# SOAL RESPONSI

Membangun REST API sederhana untuk layanan pencatatan peminjaman buku perpustakaan

## 1. Ketentuan Teknis & Fitur

- **Stack**: Node.js & Express.js
- **Database**: Supabase
- **Fitur Utama**: Operasi CRUD (Create, Read, Update, Delete) data peminjaman buku oleh anggota serta fitur filter query (contoh: `GET /loans?status=Terlambat`)
- **Deployment**: Deploy API ke **Vercel** agar dapat diakses secara publik.
- **Dokumentasi (README.md)**: Repository Github wajib dilengkapi file `README.md` yang memuat:
  - Deskripsi umum dan tujuan projek
  - Struktur data / skema
  - Contoh request dan response
  - Panduan instalasi & cara menjalankan lokal
  - Link hasil deployment vercel

## 2. Output yang dikumpulkan

- Link Repository Github (bersih, publik, memuat kode sumber & README.md lengkap)
- Link Base URL Deployment Vercel (bisa diakses dan diuji endpoint-nya)
