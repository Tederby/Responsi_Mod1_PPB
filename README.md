# REST API Layanan Pencatatan Peminjaman Buku Perpustakaan

Proyek REST API untuk manajemen dan pencatatan transaksi peminjaman buku perpustakaan oleh anggota. Menggunakan **Node.js**, **Express.js**, dan **Supabase (PostgreSQL)**, serta dikonfigurasi siap untuk dideploy ke **Vercel**.

- **Deployment Vercel**: (Sedang dideploy)

---

## Fitur

- **CRUD**:
  - `POST /loans` : Menambahkan data transaksi peminjaman baru
  - `GET /loans` : Menampilkan seluruh daftar peminjaman buku
  - `GET /loans/:id` : Menampilkan detail peminjaman berdasarkan ID
  - `PUT /loans/:id` : Memperbarui data peminjaman (status, tanggal pengembalian, dsb.)
  - `DELETE /loans/:id` : Menghapus data peminjaman berdasarkan ID
- **Filter Query Parameter**:
  - `GET /loans?status=Terlambat` : Filter data peminjaman berdasarkan status (`Dipinjam`, `Kembali`, `Terlambat`)
  - `GET /loans?search=keyword` : Pencarian buku atau nama peminjam
- **Deployment Ready**:
  - Dilengkapi konfigurasi serverless Vercel (`vercel.json` dan `api/index.js`)
- **Flexible Field Alias**: Mendukung nama field dalam bahasa Inggris (`borrower_name`, `book_title`, `loan_date`, `due_date`, `return_date`, `status`) maupun bahasa Indonesia (`nama_peminjam`, `judul_buku`, `tanggal_pinjam`, `tanggal_jatuh_tempo`, `tanggal_kembali`).

## Struktur Data / Skema Database

Tabel yang digunakan pada Supabase adalah tabel **`loans`**:

| Kolom | Tipe Data | Keterangan |
|---|---|---|
| `id` | `BIGINT` | Primary Key, Auto Increment (Identity) |
| `borrower_name` | `TEXT` | Nama lengkap peminjam / anggota perpustakaan (Wajib) |
| `book_title` | `TEXT` | Judul buku yang dipinjam (Wajib) |
| `loan_date` | `DATE` | Tanggal peminjaman (Default: Tanggal hari ini) |
| `due_date` | `DATE` | Batas waktu pengembalian buku (Default: 7 hari setelah pinjam) |
| `return_date` | `DATE` | Tanggal pengembalian buku (Bisa `NULL` jika belum dikembalikan) |
| `status` | `VARCHAR(50)` | Status peminjaman: `'Dipinjam'`, `'Kembali'`, `'Terlambat'` |
| `created_at` | `TIMESTAMPTZ` | Waktu data dibuat (Default: `NOW()`) |

### Script SQL Supabase

```sql
CREATE TABLE IF NOT EXISTS public.loans (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  borrower_name TEXT NOT NULL,
  book_title TEXT NOT NULL,
  loan_date DATE NOT NULL DEFAULT CURRENT_DATE,
  due_date DATE NOT NULL,
  return_date DATE,
  status VARCHAR(50) NOT NULL DEFAULT 'Dipinjam',
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE public.loans ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Allow public full access on loans" ON public.loans;

CREATE POLICY "Allow public full access on loans" 
ON public.loans 
FOR ALL 
TO public 
USING (true) 
WITH CHECK (true);
```

## Instalasi

### 1. Clone Repository & Install Dependencies

```bash
git clone https://github.com/Tederby/Responsi_Mod1_PPB.git
cd Responsi_Mod1_PPB
npm install
```

### 2. Config Environment Variables

Salin file `.env.example` menjadi `.env`:

```bash
cp .env.example .env
```

Buka `.env` dan config seperti berikut:

```env
PORT=3000
SUPABASE_URL=https://xxxxxxxxxxxxxxxx.supabase.co
SUPABASE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 3. Menjalankan Server

- **Mode Dev/Pengembangan (Auto-reload / Watch Mode)**:
  ```bash
  npm run dev
  ```

- **Mode Produksi**:
  ```bash
  npm start
  ```

Server jalan di: `http://localhost:3000`

## Deployment ke Vercel

Proyek ini sudah sudah ada `vercel.json` dan `api/index.js` untuk Vercel Serverless Function.

1. **Push kode ke GitHub**:
   ```bash
   git add .
   git commit -m "feat: ya allah moga bisa deploy"
   git push origin main
   ```
2. **Buka Vercel Dashboard** ([vercel.com](https://vercel.com/)):
   - Klik **Add New...** -> **Project**.
   - Pilih repository `Responsi_Mod1_PPB`. (Tergantung nama dir yang di-clone)
3. **Jangan lupa Environment Variables di Vercel**:
   Di **Environment Variables**, tambahkan:
   - `SUPABASE_URL` : URL project Supabase
   - `SUPABASE_KEY` : Anon Public Key Supabase
4. **Deploy**:
   - Klik tombol **Deploy**.
   - Tunggu proses build selesai.
5. **Uji Endpoint di Vercel**:
   - Buka browser atau Postman ke URL hasil deployment, contoh:
     - `https://<project-anda>.vercel.app/`
     - `https://<project-anda>.vercel.app/loans`
     - `https://<project-anda>.vercel.app/loans?status=Terlambat`
